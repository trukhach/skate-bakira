# Скейт Бакира

3D-скейт для Telegram (Mini App). Горизонтальный экран, сенсорное управление, работает и в обычном браузере.
Механики и структура заданий — по мотивам мобильной skate. (2007), но весь код, 3D-графика, тексты и звук сделаны заново, без файлов из оригинальной игры.

## Что внутри

```
index.html      — игра (интерфейс, меню)
icon.png        — иконка
.nojekyll       — нужен для GitHub Pages
js/engine.js    — свой 3D-движок на WebGL2 (свет, тени, туман, небо)
js/textures.js  — процедурные текстуры
js/skater.js    — модель Бакира и анимации трюков
js/levels.js    — 9 карт и 32 задания (4 главы)
js/audio.js     — звуки и музыка (синтез, без файлов)
js/game.js      — физика, трюки, линии, задания, управление
```

Карты: Учебка (4 трассы), Площадь, Центр, Стройка, Парк, Рампа.
Трюки: Олли, Кикфлип, Инди, Эйрволк, 360, Стиффи, Ростбиф, грайнды (50-50, Носграйнд, Файв-О, Бордслайд), Мануал, Лип-стол, Хендплант. Линии с множителем, стрелки баланса, «Футаж» (замедление).

## Управление

- **Левая половина экрана** — плавающий джойстик: влево/вправо — руль, вверх — разгон, вниз — тормоз. В рампе — качайся в сторону движения.
- **ОЛЛИ** — прыжок (держи дольше — выше). Можно сразу провести пальцем от кнопки — это трюк.
- **Свайп справа в воздухе**: ↑ Кикфлип, → Инди, ← Эйрволк, ↓ 360. После большого трамплина и в рампе: ↑ Стиффи, → Ростбиф.
- **МАНУАЛ**, **🎥 Футаж**, **❚❚ Пауза**.
- На ПК: стрелки, Пробел, W/A/S/D — трюки, E — мануал, F — футаж, Esc — пауза.

Если телефон держат вертикально, игра сама поворачивает картинку — просто поверни телефон.

## Проверить у себя

Открой `index.html` двойным кликом в Chrome или Edge.

## Залить на GitHub Pages

1. На github.com нажми **New repository** → имя, например `skate-bakira` → **Public** → **Create repository**.
2. На странице репозитория: **Add file → Upload files** → перетащи ВСЁ содержимое этой папки (index.html, icon.png, .nojekyll, README.md и папку `js` целиком) → **Commit changes**.
   Файл `.nojekyll` скрытый — если Windows его не показывает, включи «Показывать скрытые файлы» или пропусти его, игра заработает и без него.
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/(root)** → **Save**.
4. Через 1–2 минуты игра будет по адресу `https://ТВОЙ_ЛОГИН.github.io/skate-bakira/`

## Запустить в Telegram

1. Открой **@BotFather** → `/newbot` (если бота ещё нет) → придумай имя и username.
2. Кнопка в чате бота: `/mybots` → твой бот → **Bot Settings → Menu Button → Configure menu button** → вставь ссылку с GitHub Pages → название кнопки, например «Играть».
3. Ссылка-приложение (чтобы делиться): `/newapp` → выбери бота → название, описание, картинка 640×360 → ссылка с GitHub Pages → короткое имя, например `skate`. Получишь ссылку вида `t.me/ИМЯ_БОТА/skate`.

Прогресс сохраняется на устройстве игрока.
